# Isolated Iki + Blender prompt-to-puppet experiment (2026-11-16)

This experimental branch is independent of the earlier production InkRig workflows. It does not alter or merge the prior successful pipeline. No Colab, Kaggle GPUs or AI Horde quotas are required.

## Real inputs and mechanisms

- A fixed freeform prompt is compiled by `puppet-lab/prompt_to_motion.py` into a short 6-action JSON timeline. This is a **rule-based parser**, not an LLM, automatic illustration generator, or proof that any prompt works. Prompt customization is available via `--prompt`, limited to the documented action vocabulary.
- **Iki `zeikar/iki`, MIT**: official source cloned on the runner, pnpm build, real official 25-case auto-rig regression, then actual `autoRigFromLayers` on **Iki's own MIT sample fixture PNGs**, validation of the generated `.iki`, and Chromium/WebGL rendering of idle, open-mouth and blink PNGs. The sample PNGs are NOT generated by an AI model or from the story prompt, and this first experiment is not full-body walk animation in Iki.
- **Blender**: fresh original procedural vector scene, 12-bone armature with animated limbs and head, keyframed per frame, 6.5 seconds/104 output frames at 16 FPS, orthographic headless Workbench rendering and FFmpeg MP4. Frame-level skeleton endpoints drive newly redrawn vector parts, not still-image zoom. The .blend saves animated armature bones; its vector art at the last state is not permanently constrained via live bone drivers, so re-render via the Python script for frame-accurate art. No GPU image-to-video diffusion.
- The second workflow run is https://github.com/beutynatureenvironmentworld/prompt-2d-animation-studio/actions/runs/43754820308 . Blender job passed, with real MP4; Iki model generation and 3 WebGL pose images passed but workflow's copy directory path was missing, so a separate retry fixes artifact export.
- Blender render was validated with a changed bone angle and differing sampled PNG bytes; no claim of smooth hand-drawn 100k-frame output or 24/7 cost-free GitHub Actions.
  
## Other candidates reviewed, not installed or tested here

- `JDhruv14/line-art-animation` (MIT, TypeScript SVG + gait/motion) is promising for clean ink-on-paper movement. Official https://github.com/JDhruv14/line-art-animation .
- `MangoLion/stretchystudio` (GitHub MIT metadata, documentation/license conditions should be checked; early editor) offers mesh deformation and PSD/See-Through layer imports, but export API not proven here.
- ToonCrafter official `Doubiiu/ToonCrafter`, Wan, LTX-Video require actual compatible GPU and model weights, not simply npm/pip install on GitHub CPU. They were previously only shallow-cloned in a separate workflow. Do not claim those generated animation frames.
