# Prompt 2D Animation Studio — CPU-first and offline-first

**Prompt → editable JSON storyboard → authored moving 2D frames → music/SFX → H.264/AAC MP4**. Works without GPU, paid API keys, external models or cloud accounts.

This starting scene, inspired by a user-supplied picture, features two expressive stick-figure characters in a moonlit bedroom, floating snore Zs, animated facial expressions and blanket breathing. Forest, meadow and beach templates are also included.

**Limitations:** This is an authored, keyword-selected template engine. It does NOT convert arbitrary text, images, or videos into unlimited natural frame-by-frame AI animation. Reference media are never uploaded, segmented, motion-copied, or auto-rigged. Editing requires modifying JSON/story templates.

## සිංහල — ආරම්භය

Python 3.11+, FFmpeg සහ Pillow අවශ්‍යයි. GPU අවශ්‍ය නැහැ. පළමුව requirements install කරන්න:

    python -m pip install -r requirements.txt
    python -m studio.core doctor

එකම prompt එකකින් editable storyboard, original synth music, snoring SFX සහ video එකක්:

    python -m studio.automatic "At night two stick figure roommates; one snores and another is annoyed" --out output/bedroom.mp4

ප්‍රතිඵල: output/bedroom.mp4 සහ output/bedroom.storyboard.json. Sound නැතිව:

    python -m studio.automatic "bedroom sleep" --silent --out output/silent.mp4

Sinhala keyword-based templates: නිදන, ගොරවන, රාත්‍රී, වනාන්තර, වෙරළ. සාමාන්‍ය AI භාෂා අවබෝධයක් නොවන බව සලකන්න.

JSON edit කර scene duration/action සහ audio timeline වෙනස් කළ හැක. නව filename එකක් නොමැතිව කලින් video overwrite නොකරයි:

    python -m studio.core audio-demo
    python -m studio.core validate examples/storyboard.bedroom.json
    python -m studio.core render examples/storyboard.bedroom.json --out output/manual.mp4
    python -m studio.core plan "නිදන කාමරයේ ගොරවනවා" --out storyboard.json
    python -m studio.core render storyboard.json --out output/from-json.mp4
    python -m studio.core extend storyboard.json --seconds 2 --out extended.json
    python -m studio.core render extended.json --out output/extended.mp4

Support: 320×180, 640×360, 1280×720; FPS 12,18,24,30; 1–8 scenes, each 0.5–15s. Bedtime characters are reusable authored Python rigs in studio/bedroom.py; outdoors in studio/core.py.

## Music, narration, singing, reference files

The audio JSON timeline supports narration, music, singing and sfx as separate **manual files** with offset in seconds and volume 0–2. FFmpeg combines the tracks without executing shell code from prompts. The included music and snoring are basic deterministic original synthesized sounds—not realistic speech, AI singing or commercial music. For Sinhala dialogue use a user-recorded audio file; no verified Sinhala TTS is bundled.

Copy licensed image/video references into assets/references and add a relative reference path in storyboard JSON. That path is validated for safety but not yet analyzed or animated by the software. The uploaded screenshot/video are not bundled into the repository.

## Architecture / hybrid selection

| Role | Technology | Implementation |
|---|---|---|
| Safe offline prompt planner and editable storyboard | Python, JSON | Implemented |
| Scene drawing, faces, limbs, backgrounds | Pillow on CPU | Implemented |
| Video join, H.264 and audio mixing with AAC | FFmpeg | Implemented |
| Synthetic basic original music and snore SFX | Python wave | Implemented |
| Editable TypeScript 2D visual authoring | Motion Canvas | Optional future editor, NOT part of automatic CPU renderer |
| Headless TypeScript rendering | Revideo | Candidate, NOT integrated/installed |
| Professional animation rigging | Synfig/OpenToonz/Blender | Optional/manual, NOT installed |
| Local LLM storyboard planning | Ollama-compatible | Optional future, NOT included |
| Voice/music external integrations | Piper/Bark/Suno | Not bundled; no promise of free/API/Sinhala support |

This architecture prioritizes a verifiable starter over claims about unlimited natural AI animation. No arbitrary code generated by an LLM is executed. Path traversal, invalid scene settings and overwrites are checked.

## GitHub Actions automation

Open **Actions → CPU 2D render + tests → Run workflow**. Optionally enter a short, non-sensitive prompt. The workflow installs Python/Pillow/FFmpeg on a hosted Ubuntu CPU runner, runs tests, generates original audio, renders two sample MP4 files and uploads downloadable MP4/JSON artifacts. Workflow jobs have time and usage limits; no unlimited CPU or GPU is promised.

Local install (FFmpeg and Python must already be installed on your system):

    bash scripts/install.sh

Windows PowerShell:

    powershell -ExecutionPolicy Bypass -File scripts/install.ps1

Docker:

    docker build -t cpu-2d .
    docker run --rm -v "$PWD/output:/app/output" cpu-2d "bedroom snoring" --out output/docker.mp4

Tests:

    python -m pip install -r requirements-dev.txt
    python -m pytest -q
    python -m compileall -q studio
