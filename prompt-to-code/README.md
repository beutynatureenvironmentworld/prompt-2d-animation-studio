Prompt-to-Code 2D Animation Studio (isolated experiment). Extract Source_Project.zip into this directory for editable Python SVG, Remotion React SVG, Revideo TypeScript Canvas and shared plan scripts. GitHub Actions has independent jobs for each real renderer; verify artifacts before claiming success. Python original SVG renderer was locally measured at 2.08s for 5s/640x360 and output a verified H264/AAC MP4. Prompt compiler is an OFFLINE constrained keyword-to-JSON mapper, not an LLM. Optional external LLM plan generation lives in the source ZIP, requires opt-in endpoint and possible paid credits; it does not execute untrusted model code. Revideo fixed scene follows same story but does not import arbitrary JSON yet. Remotion is source-available with proprietary license, NOT OSI-open-source; check user eligibility for Free License: https://www.remotion.dev/docs/license. Revideo is MIT.
