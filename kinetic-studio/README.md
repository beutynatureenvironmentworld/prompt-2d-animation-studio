# Kinetic Studio

Supply one ordinary English sentence. The worker starts local llama.cpp/Qwen, generates six constrained scene decisions and stops inference before rendering. Clear object, setting and motion words in the brief override incorrect model selections when unambiguous. Matter.js integrates the prop at 120 Hz and reports contacts. The Cairo stage derives reaction timing, camera cuts and impact accents from its trajectory. FFmpeg/Flite creates a spoken punchline from the prop's dialogue template and mixes collision sounds. Each render produces a ten-second portrait cartoon and its raw inference, resolved plan and physics trace.

On the configured Oracle host, from vidbest-ai-engine:
```sh
/usr/bin/python3 kinetic-studio/film.py 'A clock falls on a rooftop at night. The courier ducks. Close up.' my-new-episode
```
On a fresh Linux x86_64 worker install node, npm, python3-cairo, ffmpeg with flite. Run the repository's free-motion/install.sh for the Qwen GGUF and pinned llama.cpp runtime, then npm install --prefix kinetic-studio. Set MOTION_RUNTIME if the model is elsewhere. No inference API or site registration.

The director supports garden, workshop or rooftop; clock, parcel or ball; drop, bounce or slide; duck, jump or reach; close or wide framing and warm or night lighting. The character and shot length are shared. Unsupported descriptions map to the nearest available choices. The pipeline generates parameters and physically simulated frames, not new diffusion art. Physics collisions are with walls and floor; character reactions are timed to the approach.
