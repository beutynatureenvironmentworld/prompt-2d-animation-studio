# LTX-2.5 render worker

The private Modal app `vidbest-ltx25` uses the Lightricks 22B distilled transformer with its published sigma schedule and synchronized audio. A single GPU container handles one shot at a time, retains the pipeline in warm memory, and scales to zero. Each call is limited to 900 seconds, with zero configured retries. Published shot lengths are 1–10 seconds at 24 fps. A 16:9 shot is 960×540, and a 9:16 shot is 540×960. Separate shots may differ in character appearance, framing and audio.

## Provision and benchmark

1. In Modal Usage & Billing, confirm remaining applicable compute credits, set the Workspace spend limit to zero out-of-pocket and confirm the saved value. If a zero limit is unavailable, keep the worker disabled for the free-only pilot. A container cap limits concurrency. The Workspace limit protects the billing account across repeated calls.
2. Sign in at [LTX-2.5-Diffusers](https://huggingface.co/Lightricks/LTX-2.5-Diffusers), review its Community License, and accept model access. Store the read token with gated-model permission as `HF_TOKEN` in a Modal Secret named `vidbest-huggingface`. The CPU staging function receives the token. The GPU worker reads the mounted snapshot without that credential.
3. From this directory, in an authenticated Modal environment, run `python -m pip install modal`, then `modal run engine.py::prepare_weights` to cache model components, and `modal deploy engine.py`. Confirm the staging function returned the configured revision. For a different environment, stage and deploy in that same environment.
4. Benchmark both target orientations. Measure cold start, GPU rendering, final encoding, transfer time and actual Modal cost from the dashboard. Record sustained throughput with queued shots before enabling paid long jobs. A 30-minute job split into 10-second shots needs 180 shots. Three hours leaves 60 seconds per shot including overhead with one GPU. Configure admission against measured capacity and the remaining budget.
5. From the trusted job processor, look up and invoke `modal.Function.from_name("vidbest-ltx25", "render_shot").remote(prompt, ratio, seconds, seed)`. The result is MP4 bytes. Keep access to the function restricted. The public client should submit only through the verified-payment order processor.

The [official model card](https://huggingface.co/Lightricks/LTX-2.5-Diffusers) supplies the single-stage distilled inference parameters. Model and Diffusers source revisions are pinned in engine.py. The build installs runtime dependencies into the Modal image; use the accepted image deployed in the benchmark when enabling real orders. [Modal workspace budgets](https://modal.com/docs/guide/budgets) and [Modal pricing](https://modal.com/pricing) describe applicable credits and spend limits.
